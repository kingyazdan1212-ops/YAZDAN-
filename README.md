# YAZDAN — پیام‌رسان واقعی

پیام‌رسان لحظه‌ای با حساب کاربری، چت خصوصی، گروه، وضعیت آنلاین و ذخیره تاریخچه روی سرور.

صفحه استاتیک روی GitHub Pages به‌تنهایی پیام واقعی رد و بدل نمی‌کند. باید این سرور Node را اجرا یا روی یک هاست رایگان دیپلوی کنی.

## اجرای محلی

```bash
cd yazdan
npm install
npm start
```

بعد در مرورگر: http://localhost:3000

دو مرورگر (یا یک عادی و یک ناشناس) باز کن، دو حساب بساز، از منو «پیدا کردن کاربر» نام‌کاربری طرف را بزن. پیام همان لحظه می‌رود.

## دیپلوی رایگان (برای گوشی و اینترنت)

۱. ریپو را روی GitHub بگذار  
۲. روی Render یا Railway یک Web Service بساز  
۳. Build: `npm install`  
۴. Start: `npm start`  
۵. آدرس عمومی را به دوستانت بده

بدون سرور آنلاین، دو نفر روی دو دستگاه نمی‌توانند به هم پیام بدهند.
